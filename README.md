# skills-jhow

Skills do Claude Code em PT-BR, feitas no dia a dia de um dev que também vende sites e produz conteúdo.

## Skills grátis

| Skill | Pra quê |
|---|---|
| `diagnosticar-bug` | Achar a causa de um bug com teste que reproduz, em vez de chutar |
| `verificar-antes-de-concluir` | Rodar a verificação e ler a saída antes de dizer "pronto" |
| `retomar-trabalho` | Salvar onde parou (`HANDOFF.md`) e retomar em outra sessão |
| `seo-specialist` | SEO, AEO e GEO para sites de negócios locais |
| `aprender-do-zero` | Roteiro em módulos, um por vez, com checagem de entendimento |

## Instalar

Copie a pasta da skill para `~/.claude/skills/` (ou `.claude/skills/` do projeto).
Depois peça em linguagem natural, por exemplo: "diagnostica esse bug".

## Skills de terceiros que recomendo

Instale direto da fonte (cada uma tem a própria licença): `ponytail`, `superpowers`
(`brainstorming`, `systematic-debugging`), `hyperframes`.
